# File; Flags
#
# Paths are relative to `<audiovectors>/vectors`. Flags are separated by spaces.
#
# Blank lines and lines whose first non-whitespace character is # are ignored.
#
# Flags:
#   FAIL_OPEN      - The file should fail at opening.
#   FAIL_DECODE    - The file should open successfully, but fail at the decoding stage.
#   SKIP_REFERENCE - Skip the external decoder comparison. All dr_libs checks must still pass.
#   UNSUPPORTED    - The file is explicitly not supported by dr_libs and will be ignored. In practice is the same as IGNORE, but is a bit clearer as to why it's being ignored.
#   IGNORE         - The file is a non-audio file and should be ignored.
#
# IGNORE and UNSUPPORTED skip both stages without a log message. FAIL_DECODE requires a successful
# dr_libs open, then a failure in decoding or validation. FAIL_DECODE still runs basic seeking,
# but skips seek comparisons because no complete decoded reference is available.
#
# Each entry selects one policy. Different policies cannot be combined.
